| `index.html`                                                                   | All site content and SEO metadata                               |

**Important:** Absolute URLs in HTML and sitemap currently point to `https://rohitpulamarasetty.github.io/`. If you publish on a different domain, update all canonical/OG/Twitter/schema/sitemap URLs before launch.

The web font and GSAP/ScrollTrigger enhancements are loaded from public CDNs. If these resources are blocked, local fallback fonts and native motion/interactions remain available. The site respects `prefers-reduced-motion`.
